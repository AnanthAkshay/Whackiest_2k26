# Microsoft Support notes

Sources: [formula overview](https://support.microsoft.com/en-us/excel/get-started/overview-of-formulas-in-excel), [number formats](https://support.microsoft.com/en-us/excel/format-numbers), [filtering](https://support.microsoft.com/en-gb/excel/get-started/filter-data-in-a-range-or-table-in-excel), [sorting](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel), [chart data selection](https://support.microsoft.com/en-us/excel/select-data-for-a-chart), [saving a workbook](https://support.microsoft.com/en-us/excel/save-your-workbook), [wrapping text](https://support.microsoft.com/en-us/excel/wrap-text-in-a-cell-in-excel), and [formatting a table](https://support.microsoft.com/en-us/excel/format-an-excel-table) — accessed 2026-11-24.

- A cell reference identifies a location or range. Relative references adjust when copied, while an absolute reference such as `$A$1` stays fixed.
- Number formats change how an existing numeric value is displayed. Currency, percentage, and date displays need attention to the stored value and its intended presentation.
- Sorting rearranges rows using a column; filtering temporarily shows a subset that matches conditions. A table supplies header-level filter controls.
- A chart starts with a selected data range. Data arrangement influences which chart type makes sense, and labels help explain the data series.
- Save As creates a copy or saves a workbook to another place or format. Wrap Text and table formatting both begin by selecting the relevant cells or range.
