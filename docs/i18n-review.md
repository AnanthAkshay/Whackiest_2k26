# Native-speaker review list

Ask Hindi and Kannada speakers to review these translation keys in `web/src/i18n/hi.json` and `web/src/i18n/kn.json` before the pilot:

- `languageTitle`, `languageBody`, `levelTitle`, `levelBody`
- `levelNewTitle`, `levelNewBody`, `levelSomeTitle`, `levelSomeBody`, `levelToughTitle`, `levelToughBody`
- `consentTitle`, `consentBody`, `start`
- `micTitle`, `micBody`, `tryAgain`, `useTextInstead`
- `sessionTitle`, `sessionStarting`, `sessionConnecting`, `elapsedTime`, `meter`, `beginner`, `agentListening`, `agentSpeaking`, `agentReady`, `mockSession`, `speakExplanation`, `typeInstead`, `useVoiceInstead`
- `textFallback`, `textPlaceholder`, `sendText`, `whatHeard`, `showTranscript`, `hideTranscript`, `recognising`
- `endSession`, `connectionFailed`, `microphoneLost`, `durationWarning`, `scoring`, `resultsEyebrow`, `resultIntro`
- `scoresTitle`, `issued`, `recordUnavailable`, `recordUnavailableBody`
- `rubricBasis`

Check that the wording is conversational, uses the intended regional register, and remains clear when read aloud on a phone.
